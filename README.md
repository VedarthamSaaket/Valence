# Valence, AI-Powered Personality Analytics Platform

A full-stack personality assessment platform combining psychology, machine learning, and data visualization.

## Architecture

```
valence/
├── frontend/          # React + Vite
├── backend/           # FastAPI (Python)
│   ├── ml/            # Scoring, clustering, UMAP
│   ├── models/        # Trained .pkl files (generated by train_offline.py)
│   ├── datasets/      # Your CSV files go here
│   └── database/      # SQLite
└── shared/
    └── questions/     # Test question JSON files
```

## Quick Start

### 1. Backend Setup

```bash
cd backend
pip install -r requirements.txt

# Optional: install umap-learn for personality map
pip install umap-learn

# Copy and fill in env
cp .env.example .env

# Run server
uvicorn main:app --reload --port 8000
```

### 2. Frontend Setup

```bash
cd frontend
npm install

# Copy and fill in env
cp .env.example .env

npm run dev
```

Open `http://localhost:5173`

## ML Training (Required for full accuracy)

### Step 1: Download datasets

| Test | Source | Download |
|------|--------|----------|
| Big Five | OpenPsychometrics IPIP-NEO | https://openpsychometrics.org/_rawdata/IPIP-NEO-data-May2018.zip |
| Dark Triad | OpenPsychometrics SD3 | https://openpsychometrics.org/_rawdata/SD3.zip |
| Human Values | ESS PVQ-21 | https://ess-search.nsd.no (Round 1+, select value items V1-V21) |
| Motivation (SDT) | BPNSS adapted | Rename your SDT CSV columns to SDT1-SDT21 |

### Step 2: Place CSVs in backend/datasets/

```
backend/datasets/
├── bigfive.csv      ← Tab-separated, columns: EXT1-EXT10, EST1-EST10, AGR1-AGR10, CSN1-CSN10, OPN1-OPN10
├── darktriad.csv    ← Tab-separated, columns: M1-M9, N1-N9, P1-P9
├── values.csv       ← Columns: V1-V21
└── sdt.csv          ← Columns: SDT1-SDT21
```

### Step 3: Run training script

```bash
cd backend
python ml/train_offline.py
```

This will:
- Clean datasets (remove invalid/missing values)
- Compute psychometric trait scores
- Find optimal K using silhouette score
- Train KMeans clustering models
- Train UMAP dimensionality reduction
- Save all models to `backend/models/`
- Print cluster centroids for manual archetype labeling

### Step 4: Label archetypes

After training, open each `backend/models/{test_id}_archetypes.json` and rename clusters based on the centroid profiles printed during training.

Example:
```json
{
  "0": {
    "id": "analytical_explorer",
    "name": "The Analytical Explorer",
    "tagline": "Curious mind, reflective presence",
    "color": "#7B61FF",
    "description": "..."
  }
}
```

## Without Trained Models

The platform works without running `train_offline.py`:
- Trait scoring works fully (psychometric formulas always run)
- Percentiles use 50th as fallback
- Archetypes use rule-based fallback
- UMAP map uses synthetic coordinates
- Similarity uses approximate estimates

For full ML accuracy, run the training script.

## Dataset Column Reference

### Big Five (bigfive.csv)
- `EXT1–EXT10`, Extraversion items
- `EST1–EST10`, Emotional Stability items (inverted → Neuroticism)
- `AGR1–AGR10`, Agreeableness items
- `CSN1–CSN10`, Conscientiousness items
- `OPN1–OPN10`, Openness items
- Values: 1–5 (Likert), 0 = invalid (will be removed)

### Dark Triad (darktriad.csv)
- `M1–M9`, Machiavellianism
- `N1–N9`, Narcissism
- `P1–P9`, Psychopathy
- Values: 1–5, 0 = invalid
